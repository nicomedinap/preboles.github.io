# Galería de imágenes – Cámaras de aeropuertos

## 1. Descripción

Este documento recopila imágenes obtenidas desde cámaras de aeropuertos, destinadas al análisis de las condiciones atmosféricas y la observación de fenómenos ópticos asociados al arrebol.

Las imágenes se encuentran alojadas en el repositorio de GitHub:

**Repositorio:** `nicomedinap/preboles.github.io`

**Directorio:** `Documentacion/Clasificacion/CamarasDeAeropuertos/`

Las imágenes se presentan mediante tablas y grillas para facilitar su comparación visual.

## 6. Consideraciones

- Las imágenes se cargan directamente desde GitHub.
- No es necesario descargar las imágenes para visualizar el documento.
- Al seleccionar una imagen se abre el archivo original.
- Las dimensiones de visualización se controlan mediante el atributo `width`.
- La organización permite incorporar nuevos registros históricos.

## 7. Objetivo del registro

Esta colección constituye una referencia visual para el análisis de las condiciones atmosféricas en diferentes ubicaciones geográficas.

Su utilización permitirá comparar:

1. Distribución y cobertura nubosa.
2. Presencia de nubes altas, medias y bajas.
3. Coloración del cielo durante el ocaso.
4. Intensidad y extensión espacial del arrebol.
5. Diferencias atmosféricas entre distintas localidades.

Estos registros pueden utilizarse posteriormente como material de referencia para la clasificación de eventos y la validación del modelo físico-estadístico de predicción de arrebol.
